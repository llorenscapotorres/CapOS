# CapOS

> A troll operating system built from scratch.

## About

**CapOS** is an experimental operating system written from scratch, currently using **x86 Assembly** compiled with **NASM** and booted through **SeaBIOS**.

The goal is to create an intentionally absurd operating system while learning how computers, operating systems, and low-level programming actually work.

The project aims to avoid relying on existing operating systems, machine learning frameworks, or numerical libraries.

## The Goal

The final objective of CapOS is to implement and train a **binary neural network directly inside the operating system**.

The neural network should be capable of answering one important question:

> Is this image Elon Musk?
