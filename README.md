# CapOS
> Ironemula operacia sistemo konstruita de nulo.

## Pri

**CapOS** estas eksperimenta operacia sistemo skribita de nulo, nuntempe uzante **x86 Asamblado** kompilitan kun **NASM** kaj startitan per **SeaBIOS**.

La celo estas krei intence absurdan operacian sistemon dum lernante kiel komputiloj, operacaj sistemoj, kaj malalta-nivela programado reale funkcias.

La projekto celas eviti dependi de ekzistantaj operacaj sistemoj, meshina lernado aroj, aux ciferaj bibliotekoj.

## Kiel Ekzekuti?

Tre facile, nur `bash CapOS.sh`.

Vi devas esti en Linuksa chirkaux (Debian, Ubuntu, WSL...)

## La Celo

La fina celo de CapOS estas realigi kaj trejni **duuman nexran reton rekte ene de la operacia sistemo**.

La nexra reto devus esti kapabla respondi al unu grava demando:

> Chx chi tiu bildo estas Elon Musk?

Dankon, kaj Dio benu vin!

# CapOS

> A troll operating system built from scratch.

## About

**CapOS** is an experimental operating system written from scratch, currently using **x86 Assembly** compiled with **NASM** and booted through **SeaBIOS**.

The goal is to create an intentionally absurd operating system while learning how computers, operating systems, and low-level programming actually work.

The project aims to avoid relying on existing operating systems, machine learning frameworks, or numerical libraries.

## How to execute?

Very easy, just `bash CapOS.sh`.

You must be in a Linux environment (Debian, Ubuntu, WSL...)

## The Goal

The final objective of CapOS is to implement and train a **binary neural network directly inside the operating system**.

The neural network should be capable of answering one important question:

> Is this image Elon Musk?

Thank you, and bless God!
